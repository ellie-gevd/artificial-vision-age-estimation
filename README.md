# 👁️ Artificial Vision Age Estimation

## 📌 Descripción

Este proyecto desarrolla un modelo de visión artificial capaz de estimar la edad aproximada de una persona a partir de imágenes faciales.

La solución utiliza técnicas de Deep Learning mediante TensorFlow/Keras y aprendizaje por transferencia con ResNet50 para construir un modelo orientado a la estimación de edad.

---

## 🎯 Objetivo

Desarrollar un modelo que estime la edad de una persona utilizando imágenes faciales y evaluar su desempeño mediante el Error Absoluto Medio (MAE).

---

## 📂 Dataset

El conjunto de datos está compuesto por:

**7,591 imágenes faciales**
Archivo **labels.csv**, que relaciona cada imagen con la edad real de la persona (real_age).

## 🔍 Proceso
Carga de datos
Análisis exploratorio (EDA)

---

## 🤖 Modelo
ResNet50 (Transfer Learning)

---

## 📈 Resultados

| Métrica  | Valor |
|---------|----------|
| MAE entrenamiento | 31.73 |
| MAE validación | 29.62|


---

## 🏆 Resultado

Se implementó un modelo basado en ResNet50 utilizando aprendizaje por transferencia para estimar la edad de las personas a partir de imágenes faciales.

---

## 💡 Conclusión

El proyecto permitió construir un flujo completo de visión artificial utilizando TensorFlow/Keras para la estimación de edad. Aunque el desempeño obtenido todavía puede mejorarse, el trabajo demuestra el proceso de preparación de imágenes, entrenamiento y evaluación de un modelo de Deep Learning aplicado a un problema real.
